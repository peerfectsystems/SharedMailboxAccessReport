# Changelog

## 1.0.0 – 2026-11-20

First release.

- Reads Full Access, Read Permission, Send As and Send on Behalf on all shared mailboxes in Exchange Online
- Flags orphaned entries, disabled accounts, guest accounts and permissions granted directly to users
- Lists shared mailboxes without any delegated access
- Writes a CSV with all entries and an HTML report with summary and findings
